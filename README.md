# SPACE Wallet

An interactive React wallet with four cards, swipe and keyboard navigation, undo, and animated wallet color selection. Built with Next.js, Motion, Tailwind CSS, and Lucide. All displayed balances and card details are sample data.

## Development

```sh
npm install
npm run dev
```

## Static production build

```sh
npm run build
```

Serve the generated `out/` directory with any static host.

Typography: Creato Display Regular and Medium. Payment brand marks are shown for demonstration.
